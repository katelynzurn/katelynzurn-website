Life Insurance Web Application Modernization Project

Contributed to the modernization of a legacy enterprise-level life insurance Java-based web application, migrating from Struts and YUI to Spring MVC and Vue.js. Focused on building new interactive pages, improving performance, and ensuring seamless integration between frontend components and backend services.

The application is containerized and deployed via AWS Kubernetes (EKS), leveraging cloud-native scalability, CI/CD automation, and secure infrastructure practices.

Note: Due to confidentiality, code and visuals for this project cannot be shared.

Key Achievements & Impact

  • Deployment times reduced to under 5 minutes, down from over 10 minutes, improving release efficiency.
  • Application maintains over 99.5% uptime, ensuring high availability for users.
  • End-users can enter and retrieve data faster thanks to modernized frontend components.
  • No maintenance windows required due to autonomous Kubernetes deployments.
  • Refactored legacy Struts 1 and YUI components into modern Vue.js components.
  • Developed a new WYSIWYG editor, replacing a 15-year-old legacy editor, enhancing usability.
  • Implemented monitoring via Dynatrace and Splunk with automated outage alerts.
